# Solar Predictive Maintenance Using Machine Learning

## Project Overview
This project predicts whether maintenance is required in a solar power system using Machine Learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- Flask
- HTML
- CSS

## Features
- Maintenance Prediction
- Risk Level Prediction
- Early Warning Alert
- Performance Indicator
- Maintenance Recommendation

## Machine Learning Model
Random Forest Classifier

## Model Accuracy
99.94%

## How to Run

```bash
pip install -r requirements.txt
python app.py
